## 0. v2 修订说明

v1 把 ItemKNN 和 ALS 当作互相竞争的模型来横向对比。**这个定位是错的**：
工业界标准架构是「多路召回 → 融合 → 排序」，ItemKNN 与 ALS 是**互补的召回通道**，
不是竞争对手。ALS 是低秩全局逼近，有意抹掉细粒度物品共现；ItemKNN 保留局部共现结构；
两者失败模式不同，组合使用才能抬高召回上限。

因此本章主线由「模型横向对比」改为「**多路召回与融合**」，MostPop 仍作为非个性化基线。

## 1. 背景与定位

现有系统使用 ALS 矩阵分解，线上候选集为**全部 80,194 个因子**（无召回阶段，直接全量打分）。
审计报告已定位线上链路两处实现缺陷（正则口径与训练不一致、候选池无热度门槛），
稀疏场景 Recall@20 = 0.00000，低于随机基线（0.000249）。

本章目的：为论文提供一个可复现、可解释的实验章节，回答"单路召回各自什么水平、
ItemKNN 与 ALS 是否互补、融合能带来多少增益"，并把已发现的实现缺陷转化为消融结论。

**规模定位**：本科论文体量。只做经典、易实现、结论清晰的方案；不做显著性检验、
不做多随机种子、不做超参网格搜索、不引入深度学习模型。

## 2. 研究问题

| 编号 | 研究问题 |
|---|---|
| RQ1 | 各单路召回的 Top-20 水平如何？非个性化热门基线（MostPop）与两路个性化召回差距多大？ |
| RQ2 | ItemKNN 与 ALS 的命中集重叠度有多低？两路并集的召回上界比任一单路高多少？ |
| RQ3 | 融合策略与融合权重如何影响效果？融合后 Recall / NDCG / Coverage 提升多少？ |
| RQ4 | 在线 fold-in 的实现细节（正则口径、候选池热度门槛）对最终效果影响多大？（消融） |

**RQ2 是全章的关键**：如果两路命中集高度重叠，融合就没有意义；如果重叠度低，
融合的价值就有了直接证据。这个分析成本极低（几行集合运算），但它是"多路召回"叙事能否成立的支点。

## 3. 数据集与切分

**数据源**：MovieLens-32M 原始评分 `data/raw/ratings.csv`（32,000,204 行）
+ 已发布模型因子 `model_item_factors`（active 版本，80,194 × 50）。

**评测用户**：从 MovieLens 用户中采样，**与系统注册用户无关**（系统仅 2 个用户有评分，
样本量不足以做统计）。两个用户分层：

| Regime | 定义 | 目标样本量 | 固定种子 | 平均训练集 | 平均测试集 |
|---|---|---|---|---|---|
| S 稀疏 | 总评分数 20–30 | 800 人 | 7 | 19.1 条 | 5.2 条 |
| D 常规 | 总评分数 ≥ 100 | 800 人（按实际可用数量） | 42 | 脚本运行时报告 | 脚本运行时报告 |

Regime S 对齐本项目真实用户量级（2–20 条评分），是主结论依据；Regime D 观察评分密度
提高后的变化趋势。

**切分方式**：每个用户按 `timestamp` 升序，前 80% 训练、后 20% 测试（leave-last-20%）。
所有通道共用同一份用户样本与同一个随机种子，保证逐用户可比。

## 4. 对比通道

### 4.1 MostPop —— 非个性化热门基线

**定义**：不做个性化，向所有用户推荐同一份榜单，按**评分人数**降序取前 20。

**作用**：下界。任何个性化召回若打不过"给所有人推同样 20 部片"就没有价值；
同时它量化了"流行度"本身的解释力——个性化相对 MostPop 的增益才是真正的贡献。
其系统级覆盖率恒为 $20/16034 = 0.12\%$，新颖度最低，是准确率之外的一组权衡。

**口径说明**：系统现有冷启动兜底 `get_popular_movies()`（`ORDER BY avg_rating DESC` + 人数门槛）
属于 TopRated 变体，与本节标准 MostPop 口径不同；现有兜底口径在讨论部分作一句对照说明。

**指标限制**：不产生评分预测，RMSE 记 N/A。

### 4.2 召回通道 A：ItemKNN（基于物品的协同过滤）

**定义**：用训练集构建物品-物品相似度，为该用户已评分物品的近邻候选打分。

**相似度**：物品 $i,j$ 的余弦相似度（用户评分向量，缺失记 0）：

$$sim(i,j) = \frac{\sum_u r_{ui} r_{uj}}{\sqrt{\sum_u r_{ui}^2}\sqrt{\sum_u r_{uj}^2}}$$

**召回打分**：取相似度最高的 $k=50$ 个邻居，加权平均：

$$score_{knn}(u,i) = \frac{\sum_{j \in N(i) \cap rated(u)} sim(i,j)\, r_{uj}}{\sum_{j \in N(i) \cap rated(u)} |sim(i,j)|}$$

用户未评过 $N(i)$ 中任一物品时 $score_{knn}(u,i)=0$（排后）。

**实现要点**：相似度矩阵规模为候选集 $16034 \times 16034$，稠密计算内存不可接受。
采用**分块稀疏矩阵乘法**（按物品分块约 1000 个，`scipy.sparse` 计算 `R_block.T @ R_full`，
逐块取 top-50 邻居）。相似度**只在训练集上计算**，避免测试集泄漏。

**参数**：$k=50$（文献常用值，不做网格搜索）。

### 4.3 召回通道 B：ALS（本系统）

**定义**：现有系统方案。离线 PySpark MLlib ALS 训练物品因子
（rank=50, regParam=0.1, maxIter=10, nonnegative=true），线上固定物品因子、
用带非负约束的最小二乘求解用户向量后打分。

**在线求解**：$\min_{p_u}\|X_u p_u - r_u\|^2 + \lambda_{eff}\|p_u\|^2$，$p_u \geq 0$，
用 `scipy.optimize.nnls` 求解。

**口径统一声明（重要）**：正式实验统一采用**与 MLlib 训练一致的正则口径**
$\lambda_{eff} = regParam \times n_u$（$n_u$ 为用户评分数），
并对所有通道统一候选集门槛 `rating_count >= 50`。
现状实现（$\lambda_{eff} = regParam$、无门槛）仅作为 RQ4 消融的对照项。
理由：现状口径下 ALS 排序能力低于随机基线，若直接作为对比基线，
会得出"矩阵分解无效"的错误结论。

> **⚠️ 2026-10-01 更新**：其中**候选集门槛部分已作废**——`rating_count >= 50` 这道门槛
> 已从生产代码中整体移除（连同 `als.min_rating_count` / `ALS_MIN_RATING_COUNT` /
> `IDENTIFIABILITY_MIN_RATINGS` / `get_movie_ids_with_min_ratings()`），在线推荐回到
> **全量因子排序**。本文档中所有出现 `rating_count >= 50`、`16,034 部`、（第 174、250 行）
> 的地方都应按"无门槛、全量候选"重新理解，或在本实验重启时重新定义。
> **λ 口径部分仍然有效**（`effective_reg_param`，与 MLlib 一致），那是正确性问题，不受影响。

### 4.4 多路召回融合（ItemKNN + ALS）

**动机**：ALS 是低秩全局逼近，有意抹掉细粒度物品共现；ItemKNN 保留局部共现结构。
两路失败模式不同 → 命中集重叠度低 → 融合抬高召回上限。
对长尾物品尤其明显：ALS 的 rank-50 因子在评分人数很少时不可靠，
而 ItemKNN 只需少量共现邻居即可打分。

**关键工程约束（必须写进论文）**：两路分数**量纲不同，不可直接相加**。
ALS 输出是裸点积（可超过 8），ItemKNN 输出是加权平均评分（约 1–5）。
因此融合前必须先做**分数归一化**（本实验统一采用 min-max 归一化到 [0,1]），
或改用对量纲不敏感的**名次融合**。不做归一化直接加权，α 扫描没有意义。

**融合策略**（三种都实现，成本都很低）：

| 策略 | 公式 | 特点 |
|---|---|---|
| 并集上界（仅分析） | $Recall@20(A \cup B)$ | 召回理论上限，不产出真实列表 |
| RRF 名次融合 | $score(i) = \sum_{c \in \{als, knn\}} \frac{1}{k + rank_c(i)}$，$k=60$ | 无需调参、对量纲不敏感 |
| 加权分数融合（主实验） | $score(i) = \alpha \cdot \tilde{s}_{als}(i) + (1-\alpha) \cdot \tilde{s}_{knn}(i)$ | 归一化后加权，$\alpha \in \{0, 0.1, \dots, 1.0\}$，可出 α 曲线 |

**α 扫描的意义**：$\alpha = 1$ 即纯 ALS、$\alpha = 0$ 即纯 ItemKNN，
曲线两端应回落到单路水平（**这是协议自检点**：若两端对不上，说明归一化或排序实现有 bug）。

## 5. 消融实验（RQ4）

两组消融，均**复用已有测量数据**：

| 消融项 | 取值 | 已有结果（Regime S，800 用户，Recall@20） |
|---|---|---|
| 正则口径 | $regParam$ → $regParam \times n_u$ | 0.01563 → **0.04906** |
| 候选池门槛 | 0 / 10 / 20 / 50 / 100 / 200 / 500 / 1000 | 0.00000 / 0.00431 / 0.02037 / **0.04906** / 0.05787 / 0.06545 / 0.07806 / 0.09024 |

**门槛消融的解释边界（必须写进论文）**：Recall@20 随门槛单调上升，但测试集本身带热度偏斜，
门槛越高越接近"只推热门"，Top20 中位评分数从 1 升到 17,091。门槛不能一味调高，
需结合覆盖率与新颖度共同判断。本实验取 50，与系统冷启动兜底口径一致。

## 6. 评测指标

| 指标 | 定义 | 适用 |
|---|---|---|
| **Recall@20**（主） | 测试项出现在 Top-20 的比例，按用户平均 | 全部通道与融合 |
| **NDCG@20**（主） | 二值相关性（命中=1）的归一化折损累计增益 | 全部 |
| **命中集重叠度 Jaccard** | 两路 Top-20 命中集的交集 / 并集（按用户平均） | ItemKNN vs ALS（RQ2） |
| **列表重叠度** | 两路 Top-20 推荐列表的 Jaccard | ItemKNN vs ALS（RQ2） |
| **并集召回上界** | $Recall@20(A \cup B)$ | RQ2，理论上限 |
| **Coverage** | 全部用户 Top-20 的并集大小 / 候选集大小 | 全部 |
| **Novelty** | 推荐物品的平均评分人数（越低越新颖） | 全部 |
| **RMSE**（辅） | 测试项预测分的均方根误差 | ALS、ItemKNN（MostPop 为 N/A） |

**统一口径约束（公平性关键）**：

- 所有通道在**同一候选集**内排序：`rating_count >= 50`，共 16,034 部
- 指标分母 = 该用户测试项 **∩ 候选集**，所有通道一致
- 同一用户样本、同一随机种子、同一训练/测试切分

## 8. 范围外（明确不做）

- 深度学习模型（NeuMF / LightGCN / SASRec）
- UserKNN（与 ItemKNN 同源代码，若导师要求可加，成本极低）
- 显著性检验、多随机种子鲁棒性、超参网格搜索
- 内容特征 / 混合推荐（"长尾条目因子不可靠"在讨论部分定性说明）
- 排序模型（LR / GBDT 精排）——本章只做召回与融合
- 在线 A/B 测试（系统注册用户仅 3 个，不具备条件）

## 9. 预期结果与证伪条件

| 预期 | 依据 |
|---|---|
| Regime S 下 MostPop 优于"现状口径的 ALS" | 已测：0.0404 vs 0.0000 |
| 修正口径后 ALS 反超 MostPop | 已测：0.0491 vs 0.0404 |
| ItemKNN 与 ALS 的命中重叠度较低（机制不同） | 待验证——**这是 RQ2 的假设** |
| 融合后 Recall@20 高于任一单路，但低于并集上界 | 待验证 |
| MostPop 覆盖率极低（0.12%），个性化通道显著更高 | 定义即得 |
| 排序指标与 RMSE 排序不一致 | 已测：现状 RMSE 0.7920 最好、排序最差 |

**证伪条件（必须如实报告）**：若两路命中重叠度很高、融合无增益，
说明两种召回捕捉的信号高度相关，"多路召回"在本数据上不成立——
这本身是有价值的负面结论，不得通过挑选 α 或指标来掩盖。

实验结果与预期不符时，**先检查评测协议**（候选集、分母、切分、种子、归一化），再下结论。

## 12. 复现方式

1. 从 `model_item_factors`（active 版本）载入物品因子矩阵；
2. 两遍流式读取 `data/raw/ratings.csv`：第一遍统计每用户评分数，第二遍抽取样本用户；
3. 逐用户按时间 8:2 切分，构建候选集（`movies.rating_count >= 50`）；
4. 各通道在候选集内打分，产出 Top-20；
5. 融合：分数归一化 → 加权 / RRF；
6. 计算 Recall@20 / NDCG@20 / Jaccard 重叠度 / 并集上界 / Coverage / Novelty / RMSE；
7. 输出结果表与 α 曲线，含随机与热门对照基线。
