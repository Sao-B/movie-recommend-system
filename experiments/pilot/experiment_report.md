## 1. 实验目的与范围

试点回答三个问题（详见 `docs/superpowers/plans/2026-10-02-pilot-classic-als.md`）：

1. 经典 ALS（Koren 2009 带偏置矩阵分解 + 交替最小二乘）的实现**正确性**；
2. 预测分越界（历史截断问题）与小众霸榜（历史冷片问题）是否依旧；
3. 评测协议自检 + 可复现性证明 + VM 资源极限画像。

范围外：ItemCF、级联、BiasMF 消融、超参扫描（第二步计划内容）。

## 2. 实验协议

| 项 | 口径 |
|---|---|
| 切分 | **每用户时序留出**：按 timestamp 升序留最后 20%（最少 1 条）；同秒并列按 movieId 决胜（确定性可复现） |
| 泄漏验证 | 真实数据实测：严格倒挂（训练晚于测试）= **0**；373 用户边界落在同一秒内（秒级时间戳粒度，非泄漏） |
| 候选集 | 训练集出现过的全部物品（无门槛） |
| 模型 | 经典 ALS：r̂ = μ + b_u + b_i + p_u·q_i，正则 λ·n（MLlib 口径），rank 50，λ=0.1，10 轮 |
| 相关性定义 | 测试条目中 rating ≥ 4.0 |
| 指标 | Recall@20、NDCG@20、RMSE、预测分越界率 |
| 冷物品 | 测试条目物品不在训练候选者剔除（MLlib coldStartStrategy=drop 口径），逐档记录剔除数 |

## 6. 核心发现：小众霸榜（试点最大价值）

**现象**：ALS Top-20 被极低支持度物品占据——用户 14664/17963/29793 的 Top-20 中分别有 15/14/12 部电影训练支持度 ≤4（中位数 1~2）；同一批欠定因子伪影（movie 117517、205425、183197…支持度 1~2）霸占多个用户榜首。10 倍数据（20k 档）未改善（ALS 0.00011 vs Random 0.00062）。

**排除实现缺陷的证据**：评测管线能区分模型（MostPop ≈ 85~140× Random）；RMSE 正常（0.827~0.879 < 常数基线）；排序代码路径（lexsort 降序）与索引映射逐行核对无误；双跑逐位一致排除随机性。

**机制**：①评分预测目标 ≠ 排序目标（预测高分 ≠ 会被消费）；②低支持度物品的 rank-50 因子欠定，点积噪声压过偏置信号（切片物品平均仅 ~8 条评分，全量约 380 条/物品，问题在切片被放大但在生产曾被观察到）。

**结论**：该问题**不是 bug 而是经典显式反馈 MF 在 Top-N 任务上的结构性短板**，正是第二步（ItemCF 精排 / ALS+ItemCF 级联 / 隐式反馈目标）的立项依据——与用户历史观察（"点 20 条好评出来都是小众电影"）完全吻合，试点以 30 万条数据给出了可复现的实验装置与数字。

## 7. 资源极限（详见 resource_report.md）

- 30 万条级：212s、swap 14MB，无压力；313 万条级：36.8min、内存 94%、swap 峰值 2.65GB（换页存活）；
- 瓶颈在 driver（Python 侧 2.75GB）而非 JVM（2.1GB）；全量 32M 需 RDD 化 / 采样评测 / 加内存上 YARN 三选一。
